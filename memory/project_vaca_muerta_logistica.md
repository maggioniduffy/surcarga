The app is named **Vaca Muerta Logística** (product/marketing name), scaffolded as the npm package **`surcarga`** directly at the repo root (not in a `vaca-muerta-logistica/` subdirectory — that path was an earlier assumption, corrected once the actual Next.js scaffold was created there). Working name — confirm final product/brand name; all identifiers should stay easy to rename.

It is a two-sided marketplace connecting long-distance truck drivers (**transportistas**) with available cargo space to oil and gas companies (**empresas**) that need to move equipment, supplies, materials, and tools to and from field locations, scoped exclusively to the Vaca Muerta region (Neuquén, Argentina).

**Why:** User specified a narrow, industry-specific marketplace (not general freight) — empresas pay a fixed fee per cargo listing, transportistas publish trips for free, no commission is ever taken. UI language is Spanish; all code identifiers stay English camelCase.
